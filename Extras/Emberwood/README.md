# The Emberwood (held back from v0.1)

An autumn forest lair on Kerbin, built with the experimental `FOREST {}` lair block. Its config and build scripts are here; the generated models and textures are not in the repository. To rebuild it, run the scripts in `Tools/` as described in the Modder's Guide, and put `Kerbin_Emberwood.cfg` back in `GameData/Xenobiology/Lifeforms/Stock/`.
